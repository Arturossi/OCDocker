OCDocker.Workbench.OptunaDashboard module
===========================================

Local Optuna dashboard launcher used by the Workbench server and CLI. When
dashboard ports are not configured explicitly, slot count follows the resolved
OCScore replica count (clamped between 1 and 50) and each dashboard binds to
the first free port after the Workbench server port.
